# Tripo B站素材参考库

Web / App 图片和非达人视频，按周期、类别、产出方及素材编号查询，支持图片放大与视频播放。所有类别默认按本周期消耗从高到低排列，筛选后保留该顺序。

产出方统一使用稳定匿名标签“代理商1、代理商2、代理商3、自供”，各周沿用同一标签。公开页面、目录和筛选不展示真实代理名称。

本站仅展示允许各代理共享的素材内容。具体投放金额、转化数据、内部分析、账户及源报表不在此仓库中。消耗仅在私有构建阶段用于排列，公开目录只保留排列后的素材，不含金额或数值排名字段。

每周追加周期，保留已发布历史。目前归档2026年11月16日至22日，共679件素材：Web图片624、App图片27、Web视频5、App视频23。

部署使用 GitHub Pages。推送主分支后，工作流先校验公开字段及文件边界，仅发布页面、白名单目录和媒体。内部登录需要独立鉴权服务，不通过此仓库存放或加载内部报告。
